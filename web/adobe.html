How to use it

  1. Unzip the download. Keep the images folder next to build_templates.jsx.
  2. In After Effects (CC 2019 or later): File > Scripts > Run Script File... and pick build_templates.jsx.
  3. It makes one composition per graphic. Names, numbers and stats are text fields in the Essential Graphics panel; team colors, runners on base and outs are controls there too.
  4. Say yes when it asks to save Motion Graphics templates, and pick a folder. In Premiere Pro, open Window > Essential Graphics, click the folder icon to add that folder, then drag a template onto the timeline and type in the Edit tab.
  5. Stretch a clip in Premiere and only the middle stretches: the in and out animations keep their speed.

Logos and photos come in as pictures. To swap one: in After Effects, right-click the picture in the Project panel and pick Replace Footage. To let editors swap it in Premiere, drag that layer into the Essential Graphics panel before saving the template.

Fonts must be installed on the computer running After Effects. If one is missing, the script uses the next one in its list (ending with Arial) and tells you which.
