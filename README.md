# Fieldhouse CG OBS (manual edition)

Broadcast graphics for OBS Studio, scored by hand. A Python script plugin runs a small local web server; every
graphic is an OBS Browser Source, and you run the show from a control panel docked inside OBS.

Baseball is the main sport (scorebugs, lower thirds, lineups, defense, pitching lines, linescores, standings, game
ops graphics and about 30 complete style packages). Basketball, football and hockey have their own scorebugs and
clocks.

This edition makes no internet calls. Every number comes from the control panel.

## Requirements

- OBS Studio with Python scripting (64-bit Python 3 set under **Tools > Scripts > Python Settings**)
- Nothing else: the plugin uses only the Python standard library, and fonts are bundled.

## Quick start

1. Download or clone this repository.
2. In OBS: **Tools > Scripts > +** and pick `obs_baseball_graphics.py`.
3. Click **Create / Update Graphics Scene**, then nest the "Baseball Graphics" scene in your program scenes.
4. **Docks > Custom Browser Docks**: name it Live, URL `http://127.0.0.1:8765/control.html?panel=live`.
   Add more docks for the other tabs if you like (`?panel=scoring`, `graphics`, `custom`, `ops`, `podcast`).
5. On the **Scoring** tab, type the team names and lineups (one per line: `1 Alex Rivera CF .312`).
6. Run the game from the **LIVE** tab.

To run it without OBS (a second computer, or for testing): `python obs_baseball_graphics.py --port 8765 --lan`
and open `http://<this computer>:8765/control.html` in a browser.

## The LIVE tab

- **On air**: every graphic currently showing. Click one to take it out, or ALL OUT.
- **Game**: score, inning, count, outs, bases, batter and pitcher.
- **Scoring pad**: Ball, Strike, Foul, Out, Walk, Single, Double, Triple, Home run, Error, Next batter, Undo.
  Pitch counts, strikeouts, the batting order and the half inning switch are handled for you. Hits move every
  runner up as many bases as the batter; tap a base to correct runners.
- **Hot buttons**: up to 20 graphics you use every game, taken with keys 1 to 9 and 0 (Shift for 11 to 20).

Keyboard on the LIVE tab: B ball, S strike, F foul, O out, W walk, N next batter, Z undo.

## Layout

| Path | What |
|---|---|
| `obs_baseball_graphics.py` | The OBS script: web server, state, hotkeys, scene builder. Also runs standalone. |
| `web/control.html` | Control panel (tabs via `?panel=`). |
| `web/overlay.html` | Transparent output page used by the OBS Browser Sources. |
| `web/editor.html` | Visual graphics editor. |
| `web/engine.js`, `engine.css` | Shared renderer and animations. |
| `templates/` | The starter package and the style packages. Generated by `tools/`; do not edit by hand. |
| `tools/` | Package builders (`python tools/build_all.py` regenerates every package). |
| `media/` | Drop-in logos, player photos, backgrounds, videos and sponsor logos (see `media/README.txt`). |
| `tests/run_manual_tests.py` | End-to-end tests (needs `pip install playwright` and `python -m playwright install chromium`). |
| `user/` | Created at runtime: your settings, saved graphics and on-air state. Not tracked. |
